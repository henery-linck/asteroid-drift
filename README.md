# Asteroid Drift

Asteroid Drift is a small 2D arcade space survival game made with Unity and C#.

Inspired by classic games like Asteroids, the game features physics-based spaceship movement, inertia, and screen wrapping gameplay.

This project is part of a personal challenge to create 10 micro-games to improve my game development skills.

---

## Gameplay

Control a spaceship using thrusters and survive as long as possible while avoiding asteroids.

The ship uses arcade-style physics:
- rotate the ship
- accelerate using thrust
- preserve momentum in space
- manage inertia carefully

The game also features screen wrapping:
- exiting one side of the screen teleports the player to the opposite side

The longer you survive:
- the faster asteroids become
- the more dangerous the screen gets

---

## Controls

| Key | Action |
|---|---|
| W | Forward thrust |
| A | Rotate left |
| D | Rotate right |
| S | Reverse thrust / brake |
